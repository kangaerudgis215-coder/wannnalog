# WannaLog

> 「したい」が出た瞬間に、逃さない。

「みたい・知りたい・行きたい・食べたい・欲しい」——日々生まれる“欲求”を、出た瞬間に保存し、行動に変えるまで忘れさせない iOS アプリ。

- **保存**：スクショ / URL / テキストを瞬時に保存し、AIが自動でタイトル・要約・カテゴリ分類
- **思い出す**：ウィジェット・通知で定期的にリマインド、達成チェックで振り返り
- **行動につなげる**：カテゴリ別に最適な導線（地図・予約・購入リンク等）を提示
- **収益**：日本特化のアフィリエイト導線（楽天 / Amazon / 食べログ / じゃらん / U-NEXT 等）、基本プラン無料
