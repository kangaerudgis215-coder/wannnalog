# 秘書の朝ルーティン（人生伴走モード）

WannaLog の開発だけでなく、オーナーの「人生の伴走」も秘書の役目とする。
オーナーが会話の中で**「おはよう」と打ったら**、このルーティンを実行して報告する。

## なぜ「おはよう」トリガーにしたか
- 毎朝7:30に完全自動で動く仕組み（Cron）も検討したが、いまの実行環境ではセッションに紐づき、
  7日で自動的に切れる制約がある（再設定が手間になる）。
- 「おはよう」と打った瞬間に確実に動く方式の方が、オーナーの「なるべく操作せず、たまに見るだけ」
  という運用スタイルに合う。

## 報告する3項目
1. **政治・経済・AI関連ニュースダイジェスト**
   - オーナー（文系大学院生・民法/法社会学・AI/アプリ開発に関心）が知っておくべき時事を、
     ネット検索で当日分まとめる。専門用語には一言説明を添える。
2. **AI最新ニュース**
   - AI業界（モデル・サービス・ツール）の当日〜直近の主要な動き。
3. **人気アプリのUI/UXひとつ解説**
   - 世界的に人気のアプリを1日1つ取り上げ、UI/UXの特徴を解説。
   - Figma や AI（生成AI）を使って、オーナーが自分のアプリ開発に応用できる具体的な手順まで示す。
