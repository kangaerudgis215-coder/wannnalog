# WannaLog｜プロダクト設計書

## コンセプト

> 「したい」が出た瞬間に、逃さない。

みたい、知りたい、行きたい、食べたい——人は一日に何十もの「欲求」を感じては、忘れていく。
スクショは埋もれる。メモはごちゃごちゃになる。Notionは複雑すぎる。

WannaLogは、**あなたのすべての「したい」を、出た瞬間に保存し、行動に変えるまで忘れさせない**アプリ。
見返せば、あなたが本当にやりたいことが見えてくる。

## ターゲットユーザー

- アイデアや「いいな」が止まらない、でも忙しい人
- スクショが溜まりすぎて見返せていない人
- やりたいことはあるのに、気づいたら忘れている人
- 20〜35歳・スマホネイティブ世代

| 📚 | 読みたい | 気になる本・記事 |
| 👕 | 着たい | 気になる服・コーデ |
| ✨ | その他 | なんでも |

## ユーザー体験の流れ

1. 「いいな」と思った瞬間
2. WannaLogを開く（3秒以内に保存完了。スクショ読み込みでタイトル・内容を自動AIまとめ）
3. カテゴリに自動で整理される
4. ウィジェット・通知で定期的に思い出す
5. カテゴリ別の行動導線：
   - 「欲しい」→ 楽天・Amazonアフィリエイト購入リンク
   - 「行きたい」→ Googleマップリンク
   - 「食べたい」→ 食べログ・予約サイト
   - 「いつまでに達成」など時期タグを付与
6. 達成したらチェック → 振り返りが生まれる

キーワード：モチベーション維持、夢を叶える、やりたいことを逃さない。

## 機能リスト

### 🏗️ MUST（MVP・Week1）

**保存**
- テキストでひとことメモ保存（AI補助）
- カテゴリをタップで選択（AI補助）
- 写真・スクショを添付して保存
- URLを貼るとタイトル・画像・説明を自動取得（OGP）
- 共有シートから他アプリ経由で直接保存
- ビジョンマップ機能（視覚的にモチベを高める、写真版マンダラート的な）

**一覧・管理**
- 写真付きカード形式で一覧表示
- カテゴリでフィルタリング
- キーワード検索
- 達成済みチェック

### 💴 日本特化のアフィリエイト導線（収益の核心）
- 「欲しい」→ 楽天・Amazon検索リンクを自動表示
- 「食べたい」→ 食べログ・ホットペッパー送客リンク
- 「行きたい」→ じゃらん・楽天トラベル送客リンク
- 「見たい」→ U-NEXT・Netflix・Amazon Prime紹介リンク
- 「欲しい」商品の価格追跡（楽天API）→ 値下がり時にプッシュ通知（今後の展望）

### 🇯🇵 日本語特化
- 日本語OCR（スクショ内テキストを認識・検索可能に）
- 楽天APIで商品候補を自動サジェスト
- 「行きたい場所」をGoogleマップ連携でピン表示

### 🔗 シェア
- アイテムをLINEで友達に共有
- 「欲しいものリスト」をURLで公開（誕生日・クリスマスのプレゼントリストに）

## 収益モデル

### メイン：アフィリエイト
ユーザーが「欲しい」を保存 → 楽天APIが商品候補を自動表示 → 「購入する」をタップ → アフィリエイトリンク経由で楽天市場へ → 購入完了で報酬発生（2〜10%）。

基本プラン無料。アフィリエイト収益を主導線とする。
