# ワンタップ・キャプチャ設計（欲求を“熱いうち”にログ化）

> 2026-07。コンセプト＝「ワンタップでビジュアライズ／欲求を熱いうちに熱いままログ化」。
> 競合「ほしもん」の共有ボタン登録が理想像。これを実現する設計と、うまくいく方法をまとめる。

## 核心：入口は「共有シート（Share Extension）」
アプリを開いて貼る、ではなく、**どのアプリからでも 共有→WannaLog** で登録できるのが本命。
（スクショの「ほしもんに欲しい物を登録」と同じ仕組み＝iOSのShare Extension）

- Amazon / ZOZOTOWN / メルカリ / 楽天 / Googleマップ / Instagram / Safari / YouTube …
  どこにいても **共有 → WannaLog → ワンタップ保存**。
- 受け取れるもの：**URL（必ず）／選択テキスト・タイトル（多くの場合。地図の店名・商品名・記事名）／画像（“画像そのもの”を共有した時のみ）**。
- WannaLog側でやること：**ドメインからカテゴリ自動判定**＋**共有タイトルを採用**＋**OGPで画像を試す**＋**1タップ保存**（またはキャンディボックスの小プレビューで即確認）。

## 3段のキャプチャ・ファネル
| 段 | 手段 | 時期 |
|---|---|---|
| ① 共有シート（本命） | どのアプリからも共有→WannaLog | **ネイティブ化後（要EASビルド）** |
| ② アプリ内で貼る | URL貼付→OGP＋カテゴリ自動（実装済み） | **今できる** |
| ③ 写真/スクショ→OCR | リンクが無い/取れない時の予備 | ネイティブ化後 |

## 画像＝「ビジュアライズ」の出し分け（正直な現実）
- **自動で画像が付く（OGPが効く）**：楽天 / **ZOZOTOWN** / YouTube / Pinterest / クックパッド / ブログ / 食べログ(多くは)。
- **タイトル先行＋あとで紐付け**：**Amazon / Instagram / X / メルカリ / 地図**。
  → 熱いうちは **タイトル＋カテゴリのプレースホルダー**で即保存。あとで **「写真を紐付ける」** ボタンで画像を足す。
- **Googleマップ**：og:image が“汎用ピン”なので画像に使わない（実装済み）。店名＋カテゴリで保存。将来は**地図サムネ（Static Map API/Mapbox無料枠）**で自動ビジュアライズ可能。

> 鉄則：**熱い瞬間の保存を、完璧な画像で止めない。** 「今キャプチャ → あとで仕上げ」を前提に設計する。

## 「紐付け専用ボタン」（登録後に仕上げる導線）
- 各カード/詳細に **「写真を紐付ける」「リンクから読み込む」** を分かりやすく置く。
- ホームに **「画像なし」フィルタ/バッジ** を出して“仕上げ待ち”をやさしく促す。
- これで「とりあえず1タップ保存」が罪悪感なく回る＝コンセプトの実装。

## ドメイン→カテゴリ自動（実装済み）
通販→欲しい／レシピ→作りたい／動画→見たい／グルメ→食べたい／地図→行きたい。（`guessCategoryFromUrl`）

## Amazon/メルカリも“ほしもん並み”にしたい場合（任意・後日）
端末から直接取得では限界があるので、**小さなサーバー（Cloudflare Workers/Vercel 無料枠）**を1枚挟む：
- サーバー側でOGP取得（良いIP・ヘッダー・リトライ・必要ならヘッドレス）。
- **楽天API（無料）／AmazonアソシエイトPA-API（審査・売上要件）**で商品情報を正規取得。
- これで Amazon/メルカリ/ZOZO の画像・価格が安定。※ネイティブ化とは独立して作れる。

## 実装ロードマップ（提案）
1. **今（Expo Go）**：② URL貼付のOGP＋自動カテゴリ（済）、マップのロゴ回避（済）、詳細に「リンクから読み込む/写真を紐付ける」を追加（次にやれる）。
2. **7月（ネイティブ化直後・最優先）**：**① Share Extension**（`expo-share-extension` 等の config plugin＋EASビルド。Expo Goでは不可）。＝コンセプトの心臓。
3. **その後（任意）**：小さなサーバー＋API（Amazon/メルカリ/価格追跡）、地図サムネ。

## まとめ
- 「熱いうちにワンタップ」の答えは **共有シート**。これをネイティブ化直後の最優先に。
- 画像は **取れる所は自動／取れない所はワンタップ後に紐付け**、の二段構えで“止めない”。
- Amazon等まで自動化するなら **小さなサーバー＋公式API**（後日・独立して可能）。
