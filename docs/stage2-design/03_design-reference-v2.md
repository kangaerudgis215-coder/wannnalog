# デザインリファレンス v2（更新モック採用）

作成日：2026-06-19 / 出典：オーナー提供のAI生成モック（4画面：ホーム／詳細／ビジョンボード／通知）
位置づけ：**これを正式なデザイン目標（North Star）とする**。MVPはこの一部を作り、残りは段階的に。

---

## キャッチコピー（採用）
- ロゴ：✨グラデのスパークル＋「WannaLog」／タグライン「したい！を、逃さない。」
- ヒーロー：**「見て楽しい、私の『やりたい』ぜんぶここに。」**（“やりたい”をコーラルで強調）
- サブ：「みたい、行きたい、食べたい、欲しい、やりたい…すべての欲求を、出た瞬間に保存。見返せば、あなたの夢が動き出す。」
- 配信：**iOS優先（App Storeのみ）**。

## v1モックからの主な変化
1. **ビジョンボードが主役級に昇格** → 下タブに独立タブ「ビジョン」。
   - 下タブ：**ホーム／ビジョン／＋／通知／マイページ**（リマインド→通知に名称統合）。
2. **詳細画面が構造化情報リッチに**：住所・営業時間・定休日・予算・公式サイト＋地図埋め込み＋関連写真。
3. **カードに価格・値下げ表示**（欲しい例：AirPods Pro ¥34,800 ↓12%）。
4. **通知が“スマート/文脈型”**：値下げ／予約可能化／配信開始／場所接近。
5. カードのカテゴリタグは写真の下寄せ小ピル。

## 段階ロードマップ（夢を殺さず、作れる順に）

> 原則：**“見て楽しい・わくわく”は前倒し**、**“裏で賢く動く連携”は後ろ倒し**（一人開発の体力＆Apple審査の都合）。

### 🟢 Phase 0：MVP（まず自分が30日使えるか）
- ホーム（横断2列ボード・フィルタ・検索）
- 保存（テキスト／URL〔OGP〕／写真添付）＋AI自動まとめ（タイトル/カテゴリ/タグ/期限）
- 詳細（写真・タグ・**手に入る範囲の情報**・アクションリンク〔食べログ/地図検索〕・達成チェック）
- **ビジョンボード（閲覧版）**：保存写真をグリッド/コラージュで眺める（自由配置編集は簡易 or 後）
- 達成チェック＋叶えたコレクション
- 通知：**ローカル通知（保存3日後・期限ベース）テキスト＋絵文字**
- 端末内保存（クラウド同期なし）

### 🟡 Phase 1：わくわく強化
- ビジョンボードの**自由配置編集**（ドラッグ配置・ラベル・テーマ）
- 写真付きリッチ通知／月次「今月のあなた」Wrapped
- マソンリー化／拡大トランジション
- スクショOCR自動取込

### 🔵 Phase 2：スマート連携（“賢い通知”＝差別化の最終兵器）
- 詳細の**構造化情報自動取得**（店舗の営業時間/予算/地図：Maps系API）
- **値下げ通知**（欲しい・楽天API等で価格追跡）
- **配信開始通知**（見たい・配信監視）／**予約可能通知**（食べたい）
- **位置情報リマインド**（行きたい場所に接近で通知）
- クラウド同期・アカウント・公開リスト共有

> ⚠️ Phase 2は技術的にもコスト的にも重く、各社API規約・Apple審査(3.2.2)の確認が必須。**MVPの手応え（自分＋知人が使い続ける）が出てから**着手する。先に作り込まない。

## 守るポジショニング（再確認）
アプリの主目的は **「保存・想起・夢の可視化」**。値下げ/購入/予約などのアフィリ要素は **詳細画面のアクション＝副次**。これを主目的に見せない（Apple 3.2.2リジェクト対策）。
