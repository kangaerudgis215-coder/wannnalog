# ビジョンボード「夢の地図」実装計画（v4・Skia版）

このドキュメントは、ビジョンボードを **ハニカム（六角形タイル）の「夢の地図」** に作り替える最終仕様（v4）と、その技術的な実装計画を保全するものです。
この環境は一時的なので、**ネイティブ化（EAS開発ビルド）を始めるときに、ここを見れば着手できる**状態にしておきます。

- 決定：**v4に忠実なSkia版を、ネイティブ化（開発ビルド）の一環として実装する**（オーナーはMac所持・EAS Build経験あり）。
- タイミング：**ネイティブ化フェーズ（目安7月〜）**。それまでは現行の「Pinterest風2カラム・マソンリー版」を Expo Go で使い続ける。
- v3（Pinterest版）は Expo Go での“つなぎ”として温存。夢の地図が完成したら差し替える。

---

## 0. なぜ今すぐ実装しないか（最重要の制約）

- v4は技術方針で **`@shopify/react-native-skia`** を要求している（ガラスの質感・継ぎ目の虹色リムライト・ノイズの核）。
- **Skia は Expo Go に含まれていない**。→ Skia を入れた瞬間、アプリは **Expo Go では開けなくなる**。確認には **開発ビルド（Dev Client / EAS Build）** が必須。
- したがって「夢の地図」は **開発ビルド前提の機能**。現行の Expo Go 版（Pinterest）とは別レーンで進める。
- `react-native-reanimated` と `react-native-gesture-handler` は Expo Go にも入っているが、Skia が入る時点でどのみち Dev Client が必要になる。

---

## 1. データモデル（確定・v3から継続。増やさない）

1つの「ウィッシュ（島）」が持つ項目（`app/vision.js` の現行スキーマに `q, r` を足すだけ）：

- `title`（必須・テキスト）
- `categoryId`（必須・色とアイコンのみで表現。**地図上に文字ラベルは出さない**）
- `timing`（任意・プリセット/独自ラベル/日付のいずれか1つ）
- `status`（必須・`want`=叶えたい / `doing`=叶えている最中 / `done`=叶った）
- `imageUri`（任意・1枚のみ）
- `memo`（任意・1つ）
- **`q, r`（新規・ハニカムの軸座標。自動採番、スワップで並べ替え可能）**

【禁止事項（絶対に追加しない）】数値目標・進捗％、チェックリスト・サブタスク、習慣ログ・ストリーク、複数画像、複数コメント履歴。
※現行コードにこれらは無い（ビジョンはクリーン）。箱庭（garden）は別機能で非表示のまま。

## 2. 追加する依存ライブラリと設定（開発ビルド）

| ライブラリ | 用途 | 備考 |
|---|---|---|
| `@shopify/react-native-skia` | ガラス質感・継ぎ目のブラー/グラデ/ノイズ・虹色リムライト | Expo Go 不可。Dev Client 必須 |
| `react-native-reanimated` | パン/ピンチ/長押しドラッグの物理（スプリング） | babelプラグイン `react-native-reanimated/plugin` を `babel.config.js` の最後に追加 |
| `react-native-gesture-handler` | ジェスチャー（既に導入済み ~2.28） | ルートを `GestureHandlerRootView` で包む（済） |
| `expo-haptics` | 触れる/光る/スワップ/達成のハプティクス（導入済み） | |

設定チェックリスト：
- `babel.config.js`：`plugins: ['react-native-reanimated/plugin']`（必ず最後）。
- `app.json`/`eas.json`：Dev Client 用プロファイル（`developmentClient: true`）。`app/eas.json` は既にあるので dev プロファイルを追加。
- Skia のバージョンは Expo SDK 54 / RN 0.81 に合うものを `npx expo install @shopify/react-native-skia` で入れる（SDKに合わせるのが安全）。
- reanimated も `npx expo install react-native-reanimated`。

> 破壊回避：これらを入れると Expo Go では起動しなくなる。**Dev Client をビルドできる状態になってから**追加する。追加は小さくコミットし、まず「空の地図が描ける」ところで一度ビルド確認する。

## 3. ハニカム（六角形）の構造

- **軸座標系 (q, r)** で管理（pointy-top / flat-top はデザインで選ぶ。写真は正方形寄りなので **flat-top** が収まりやすい）。
- 中心 (0,0) から外側へ**リング状**に広がる。新規ウィッシュは「同じカテゴリの島に隣接する空きマス」へ優先自動配置。
- 画面座標への変換（flat-top の例）：
  - `x = size * (3/2 * q)`
  - `y = size * (√3 * (r + q/2))`
  - 隣接6方向：`(+1,0)(+1,-1)(0,-1)(-1,0)(-1,+1)(0,+1)`
- **仮想化**：ビューポート（現在のパン/ズーム）に入るタイルだけ描画。全タイルの (q,r)→画面座標を計算し、画面外は描画しない。ズームで大量になっても軽く保つ。

---

## 4. 見た目（ガラスの質感レシピ／Skia）

各島（ガラスパネル）に必ず入れる：
1. ごく薄いノイズ/グレイン（不透明度2〜4%）… Skia の `Turbulence`/`FractalNoise` シェーダ。
2. 角（左上→右下）の白い縁ハイライト … Skia の線形グラデ縁取り。
3. 下の写真の支配色を5%だけ吸ったティント。
4. ごく薄いドロップシャドウで浮かせる。

継ぎ目：
- 隣接タイルの写真の端を **ブラー＋アルファグラデ**で溶かす（直線境界にしない）。
- 継ぎ目に**ごく細い虹色（イリデセント）リムライト**を這わせる。**彩度は低く**「気づいたら虹色」程度。
- レンダリングコストが高い。**iOS実機で早期にFPSを確認**（Androidは対象外だが重い演出なので注意）。

背景キャンバス：**白/オフホワイトの単色**。幻想的な空・レンズフレア・ボケ光は**常時背景には使わない**（達成演出と初回起動のみに温存）。

---

## 5. ステータスの見た目

- `want`（叶えたい）：静かなガラス、控えめ。
- `doing`（叶えている最中）：ごく僅かな光の脈動（強く光らせない）。
- `done`（叶った）：**金色の常時グロー**。位置は動かず、そのマスに永久に留まる「モニュメント」。

---

## 6. 操作（gesture-handler + reanimated）

- ピンチでズーム、ドラッグでパン（スプリング物理。**linearイージングは使わない**）。
- タップ → 詳細へ（写真がそのまま拡大するシームレス遷移）。
- 長押しで島を持ち上げ（ハプティクス）、別の島の上にドラッグ → **2島の位置をスワップ**（自由配置でなくスワップ方式）。確定でハプティクス＋スプリングで収まる。
- ハプティクスの発火点：島に触れた瞬間 / 継ぎ目が光る瞬間 / スワップ確定 / 達成確定。

---

## 7. 達成フロー（確認ダイアログは使わない）

1. 島を長押ししてホールド継続 → **リング状プログレスが満ちる**インタラクティブ確認（テキストのアラートは出さない）。
2. ホールド完了後、詳細と同じ質感の**ガラスの虹色ピル型ボタン**が現れ、タップで達成確定。
3. 確定と同時に**フルスクリーン祝福演出**：写真主役の光＋コンフェッティ。**日付・「〇日で叶えました」等の日数表示は一切しない**。**英語の短い一言のみ**（雰囲気はワナログに寄せる）。※現行の英語演出（Confetti＋Sparkles＋カード飛ばし）を流用でよい。
4. 演出後、該当スロットにズームインしたまま金の光が灯り、ズームアウトして地図全体へ。
5. ステータスはいつでも手動で戻せる（戻すと金グローは消える）。

---

## 8. 「叶った夢」ページ

- 地図上から消えず位置も動かないため、このページは「移動先」ではなく **アルバム/総集編**。
- 叶った順（達成日が新しい順）の画像中心ギャラリー（現行 `AchievedModal` を流用）。

---

## 9. 新規追加（FAB）

- 右下に**虹色に光るガラスのFAB**。タップで作成フロー。
- 入力順：タイトル → カテゴリ → 時期（任意）→ 画像1枚（任意）→ メモ（任意）。必須はタイトルとカテゴリのみ（現行 `VisionAddModal` を流用）。
- 追加された島は、対象カテゴリの空きマスへ**アニメーションではまり込む**演出。

---

## 10. 段階的な進め方（この順で小さくコミット）

1. **開発ビルド基盤**：reanimated + skia を入れ、babel/eas を設定し、Dev Client を1回ビルド。「空の白背景に六角形が1枚描ける」ところまで（実機FPS確認）。
2. **ハニカム配置＋操作**：(q,r)配置・仮想化・ピンチ/パン・タップ詳細・長押しスワップ。まだ質感は素の画像でよい。← ここで一度オーナー確認。
3. **ガラス質感＋継ぎ目**：ノイズ/縁ハイライト/ティント/影、継ぎ目のブラー＋虹色リムライト。実機FPS再確認。
4. **達成フロー**：ホールド→ガラスボタン→祝福演出→ズームイン金グロー→ズームアウト。
5. **仕上げ**：左端のアイコン縦レール（カテゴリ絞り込み）、FABはめ込み演出、初回起動の幻想演出。

## 11. 自己チェック（実装後に必ず）

1. 画像が主役として大きく表示されているか。
2. ハニカムの継ぎ目とホールド達成演出に**日付/日数が出ていない**か。
3. 常時表示の背景が過度に装飾的になっていないか（白/オフホワイト単色か）。
