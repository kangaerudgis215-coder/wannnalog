# WannaLog UI/UXコンセプト設計書 v1.0

担当：リードデザイナー / 想定読者：文系・デザイン初心者の個人開発者
前提：React Native (Expo) で現実的に作れる範囲で、最大限おしゃれに。

---

## 1. デザインコンセプト一言（世界観）

> **「あなたの“したい”が、眺めるだけで叶いそうになる夢の地図。」**

WannaLogは ToDo ではない。**自分の欲望をうっとり眺めるためのビジョンボード**。開くたびに「あ、これやりたかった」とワクワクが再起動する。整理する場所ではなく、**夢を思い出す場所**。
North Star（全判断の基準）＝「**忘却を倒し、わくわくを灯す**」。

## 2. トーン&マナー

写真が主役。**アプリ自身の色は控えめにして写真を引き立てる**。背景や文字は静かに、アクセントだけ華やかに。

### A案：Warm Cream（あたたかいクリーム）← 初期推奨・食べたい軸と好相性
| 役割 | 色名 | HEX |
|---|---|---|
| 背景ベース | クリームホワイト | `#FAF7F2` |
| カード面 | ピュアホワイト | `#FFFFFF` |
| メイン文字 | チャコール | `#2B2724` |
| サブ文字 | ウォームグレー | `#9A9088` |
| アクセント | コーラルオレンジ | `#FF6B4A` |
| サブアクセント | ハニーゴールド | `#F2B544` |

### B案：Midnight Gallery（夜の美術館）← かっこいい・没入感
| 役割 | 色名 | HEX |
|---|---|---|
| 背景ベース | インクネイビー | `#15161C` |
| カード面 | チャコールパネル | `#21222B` |
| メイン文字 | オフホワイト | `#F4F2EE` |
| サブ文字 | スレートグレー | `#8C8E99` |
| アクセント | エレクトリックミント | `#5EE6B5` |
| サブアクセント | サンセットピンク | `#FF7AA2` |

### フォント
- 見出し：`Noto Sans JP` Bold / または `LINE Seed JP`。英数字は `Poppins`/`Outfit`。
- 本文：`Noto Sans JP` Regular。`expo-font`＋Google Fontsで簡単導入。
- NG：明朝体、極細フォント。

### 質感
- 角丸：カード16〜20px、ボタン14px。直角NG。
- 影：ごく薄く（不透明度8〜12%、ぼかし大）。
- 余白：画面左右20px、要素間12〜16px。線でなく余白で区切る。
- 鉄則：**「迷ったら余白を足す。線を引かない。影は薄く。」**

### 写真の見せ方（最重要）
- 写真は絶対に主役。カードは写真をほぼ全面。
- 縦横比は混在OK（Pinterest風マソンリー）＝「眺めて楽しい」の正体。
- 画像なしアイテムはカテゴリ色グラデ＋大きな絵文字で代替。空白を作らない。

## 3. 主要画面の設計

### 3-1. ホーム（ビジョンボード）＝心臓部
- 上部：あいさつ＋検索／横スクロールのカテゴリ・フィルタチップ（ぜんぶ/🍜/🗺️/👀/🛍️/✅）。
- メイン：2列マソンリー写真カード。右下に＋保存FAB。
- 横断表示がデフォルト（「ぜんぶ」初期選択）＝欲求の地図。
- カテゴリは色でなく絵文字＋小ドットで表現。期限近は「あと3日」をコーラルで小さく。
- 演出：スクロールで写真がふわっと立ち上がる。pull-to-refreshで「今日のひとこと」。0件時はサンプルカードで誘導。

```
┌──────────────────────────────┐
│  おかえり、今日の“したい”は？ 🔍 │
│ (ぜんぶ)(🍜食べたい)(🗺️行きたい)… │
│ ┌──────────┐ ┌──────────┐ │
│ │██ 写真 ██│ │██ 写真 ██│ │
│ │二郎系ラーメン│ │ 北欧旅行   │ │
│ │🍜・あと3日 │ │ 🗺️        │ │
│ └──────────┘ └──────────┘ │
│                       ╭───╮ │
│                       │ ＋ │ │
│                       ╰───╯ │
└──────────────────────────────┘
```

### 3-2. 保存フロー＝3秒の気持ちよさ
1. ＋で下からシート →［📋ペースト］［🖼️写真から］［⌨️手入力］。
2. 入れた瞬間「✨AI解析中」（キラキラ1〜2秒）。
3. AIがタイトル・要約・カテゴリ・期限を埋めて提案。ユーザーは確認だけ。
4. ［保存する］でホームに新カードがポンッと着地。
- 期限は入力でなく選択（なし/今週/今月/日付）。タイピングを減らす。
- 「速い」より「待っても気持ちいい」を作る。

### 3-3. アイテム詳細＝行動への発射台
- 大きな写真／大見出し／カテゴリ＋期限。
- **行動ボタンが達成ボタンより上**（まず行かせる）。
- 食べたい→食べログ/地図、行きたい→地図、欲しい→検索/購入、見たい→検索（`Linking.openURL`）。
- ［✅達成した！］は大きく下部に。期限近は🔥でそっと急かす（責めない）。

### 3-4. リマインド/通知＝“忘却を倒す”核（裏の勝ち筋）
- 原則：責めない・急かさない・思い出させる。「やってないよ」でなく「これ、まだ楽しみにしてるよね？」。
- **写真リッチ通知**（保存写真を載せる）。文字だけより一気に再点火。
- 頻度は少なく質高く。週1〜2回、絶妙な1通。
- 文例：「🍜 “一蘭 渋谷店”、まだ食べてないね。今週末どう？」
- タイミング：保存3日後に1通目／期限「今週」は金曜夕方／食べたいは昼前・夕方。
- `expo-notifications`でローカル通知（サーバー不要）。写真付きは後回し、まずテキスト＋絵文字。
- 通知タップでアイテム詳細へ直行（思い出す→即行動を最短に）。

### 3-5. 達成・振り返り＝ご褒美の瞬間
- ［✅達成した！］で紙吹雪／キラキラ＋ゴールドの「叶えた」スタンプ＋「今月N個目！」。
- アイテムは消さず**「叶えたコレクション」**へ移動（実績＝自分の歴史）。
- 月末に「今月のあなた」サマリー（Spotify Wrapped風、シェアしたくなる）。
- 達成数の節目でバッジ解放。
- 紙吹雪は`react-native-confetti-cannon`で一発。

## 4. マイクロインタラクション（Expo実現可能）
| 場面 | 動き | 実装 | 難易度 |
|---|---|---|---|
| ボタン押下 | 沈む＋触覚 | reanimated+expo-haptics | 易 |
| カード出現 | 下からフェードイン | reanimated FadeInDown | 易 |
| 保存完了 | ポンッと着地＋ハプティクス | スケール | 中 |
| AI解析中 | シマー | reanimated/Skeleton | 中 |
| 達成 | 紙吹雪＋スタンプ | confetti-cannon | 易 |
| 拡大トランジション | shared element | navigation | 難→通常遷移で代替 |

`react-native-reanimated`＋`expo-haptics`を入れるだけで質感が一段上がる＝最優先。動きは「速め・短め・控えめ」（0.2〜0.3秒）。

## 7. 実装の現実性メモ（Expo視点）
| UI要素 | 作りやすさ | 初心者向け代替 |
|---|---|---|
| マソンリー2列 | △ | まず均一2列グリッド、後でマソンリー化 |
| 写真表示 | ◎ `expo-image` | そのまま |
| 保存シート | ◎ `@gorhom/bottom-sheet` | 普通のモーダルでも可 |
| 外部リンク | ◎ `Linking.openURL` | そのまま |
| ローカル通知 | ◎ `expo-notifications` | テキストから、写真は後 |
| 写真付き通知 | △ | MVPは絵文字＋テキスト |
| 紙吹雪 | ◎ ライブラリ一発 | confetti-cannon |
| 拡大トランジション | ✕ 難所 | 通常遷移で十分 |
| ハプティクス | ◎ `expo-haptics` | 最優先（コスパ最強） |

**最重要**：難所（マソンリー・拡大トランジション・写真付き通知）は全部「後で」でいい。MVPは「均一グリッド＋普通の遷移＋テキスト通知」でも、配色・余白・写真・ハプティクス・紙吹雪が丁寧なら十分美しい。

## 付録：挫折しない実装順
1. デザイントークン（色/余白の定数）を1ファイルに集約。
2. ホーム（均一2列グリッド）＋ダミーデータで「眺めて楽しい」を先に体感。
3. 保存シート（手入力だけ）。
4. アイテム詳細＋外部リンクボタン。
5. AI提案を保存フローに接続。
6. ローカル通知（テキスト）。
7. 達成チェック＋紙吹雪。
8. 余裕が出たら：マソンリー化→写真付き通知→振り返りサマリー。
