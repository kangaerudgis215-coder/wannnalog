# プロダクトの核（North Star）

オーナーの言葉（2026-06-19）より：

> 欲しいもの・こと・やりたいこと・見たいものが一覧になり、モチベ維持やビジョンマップのような“わくわく”を提供したい。
> そこから直接、実行への導線も確保したい。そして**洗練されたUIが最も重要**。

## WannaLog が提供する感情価値

- **一覧で見渡せる**：自分の「したい」が一画面に集まり、自分の欲求の地図が見える。
- **見るだけでワクワクする**：写真ベースのビジョンマップ。眺めるとモチベが上がる。
- **行動に移せる**：そこから予約・地図・購入などへワンタップで進める。
- **夢に近づく感覚**：達成チェックで「叶えた」が積み上がる。

## 第一原則

1. **UIが最重要**。機能の多さでなく、見た瞬間の美しさ・気持ちよさで勝負する。
2. **わくわくを設計する**。整理ツールではなく「夢が見えるボード」。
3. **想起のタイミング精度**が裏の勝ち筋（通知の質）。

## スコープの考え方（“絞る”の正しい意味）

「食べたい1カテゴリに絞る」は **重い裏側実装（行動導線・API連携）** の話であり、
**“見て心が動く体験”は絞らない**。

| 要素 | MVPでの扱い |
|---|---|
| 横断の一覧 ＋ ビジョンマップ ＋ わくわくUI | **最初から作る**（心臓部・差別化の本丸） |
| 行動導線（予約/購入/地図リンク）・各種API連携 | まず「食べたい」を軸に磨き、他カテゴリは段階追加 |
| 共有シート・ウィジェット | 後回し（Expoで最難関） |
| 収益（アフィリ副次・将来買い切り） | MVPは収益ゼロ |

→ 横断ビジョンは「将来の話」ではなく、**MVPの見た目から存在する**。
