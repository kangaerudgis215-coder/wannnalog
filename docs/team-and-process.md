# 開発チームと進め方

WannaLog は、役割を持った AI エージェントによる「チーム開発」で進めます。
オーナー（あなた）は**秘書**とだけ会話すれば、開発が前に進む体制を目指します。

## チーム編成

| 役割 | ミッション |
|---|---|
| 🗒️ 秘書 | オーナーの唯一の窓口。各専門家へ指示・議論の整理・要点報告・承認取得を担う |
| 🔍 市場調査・競合分析 | 市場性・競合・トレンド・リスクを調査 |
| 💰 マネタイズ専門家 | アフィリエイト導線・課金・収益設計 |
| 🎨 デザイン・UI担当 | 画面設計・体験設計・トーン&マナー |
| 📣 SNS戦略・マーケ | 集客・ローンチ・グロース戦略 |
| 🔥 専属批判家 | すべての案を批判的に検証し、品質を上げる |

## 運用ルール（実態）

- AI が常時自走して議論し続けることはできないため、**秘書が各ステージごとに専門家エージェントを起動**し、議論・批判・修正させたうえで成果をまとめる。
- 成果物はすべて `docs/` 配下にファイルとして残し、コミットして保全する（実行環境は一時的なため）。
- 重要な判断・費用発生・方向転換は、必ず秘書からオーナーへ報告し**承認**を得てから進める。
- 進め方そのものも、各ステージ終了時に振り返り、洗練させていく。

## 報告フォーマット（秘書 → オーナー）

各ステージ完了時に以下を報告：
1. **今回やったこと**（1〜3行）
2. **重要な発見 / 専門家の主張**
3. **批判家からの指摘と、それへの対応**
4. **意思決定が必要な点**（選択肢つき）
5. **次のステップ提案**
