# WannaLog アプリ（Phase 0：最小スライス）

これは「保存 → 3日後に通知で思い出す → 行動 → 達成チェック」という**習慣ループ**だけを切り出した、検証用の最小アプリです。写真・AI・スマート通知は後のフェーズで載せます。

> 🎯 検証したいこと：「保存したものを通知で思い出して、行動したくなるか？」を自分＋知人2〜3人で体験する。

## はじめての起動（Windows PC）

### 1. PCに3つインストール（初回だけ）
1. **Node.js（LTS版）** … https://nodejs.org/ →「LTS」をインストール
2. **VS Code**（エディタ）… https://code.visualstudio.com/
3. **Git** … https://git-scm.com/download/win

インストールできたか確認（PowerShellやターミナルで）：
```
node -v
git --version
```
バージョン番号が出ればOK。

### 2. iPhoneに「Expo Go」を入れる
App Storeで **Expo Go** を検索してインストール。

### 3. このコードをPCに持ってくる
```
git clone <このリポジトリのURL>
cd wannnalog/app
npm install
```
> `npm install` は初回だけ。少し時間がかかります。

### 4. アプリを起動
```
npx expo start
```
ターミナルに**QRコード**が出ます。

### 5. iPhoneで開く
- iPhoneとPCを**同じWi-Fi**につなぐ。
- iPhoneの**カメラ**でQRを読み取る →「Expo Goで開く」をタップ。
- WannaLogが起動します！🎉

## 習慣ループの試し方（ここが本番）
1. 右下の **＋** で「したい」を1つ保存（例：行きたいカフェ）。
2. 保存したカードをタップ → 詳細画面へ。
3. **「🔔 今すぐテスト通知（10秒後）」** を押す。
4. iPhoneを**ロック**して待つ → 約10秒後に通知が届く。
5. 通知をタップ → そのアイテムが開く → **「✅ 達成した！」** を押す。

この「思い出して→行動→達成」が**気持ちよかったか**を、ぜひ知人にも試してもらってください。

## うまくいかない時（初心者がハマりがちな所）
- **QRが繋がらない** → PCとiPhoneが同じWi-Fiか確認。ダメなら `npx expo start --tunnel` で起動。
- **エラーが出る** → Nodeは必ず**LTS版**を。古い記事のコマンドを真似しすぎない。
- **通知が来ない** → iPhoneの設定でWannaLog(Expo Go)の通知を許可。サイレント/集中モードを確認。
  - ※Expo Goでは通知機能が一部制限される場合があります。基本のローカル通知は動きますが、もし不安定なら後で「開発ビルド」に切り替えます（その時は秘書が案内します）。

## 技術メモ（参考）
- React Native + **Expo SDK 56**
- 保存：端末内（AsyncStorage）。クラウド同期はまだ無し。
- 通知：`expo-notifications` のローカル通知（サーバー不要）。
- 触覚：`expo-haptics`。
- デザイン定数：`theme.js`（Warm Cream配色・カテゴリ定義）。
